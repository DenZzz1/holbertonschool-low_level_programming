# Singly Linked Lists

Ce projet implémente des listes chaînées simples en C.

---

## Fichiers

- `0-print_list.c` : Fonction qui affiche tous les éléments d'une liste
- `lists.h` : Fichier d'en-tête avec la structure et les prototypes

---

## Compilation
```bash
gcc -Wall -pedantic -Werror -Wextra -std=gnu89 0-main.c 0-print_list.c -o a
```
